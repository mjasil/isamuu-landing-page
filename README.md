# Isamuu Landing Page

A fast, responsive landing page with a single Telegram call to action.

## Conversion tracking

- Meta Pixel ID: `2191582154875549`
- Page load: `PageView`
- Telegram CTA: `Lead`
- Additional custom event: `TelegramCTAClick`

For Ads Manager optimization, use the standard `Lead` event.

## Preview

Open `index.html` in a browser. No build step is required.
